# Grandma's Cat Coalition website

Fast, accessible website for adoption, fostering, TNR, donations, and rescue updates. Built with Vite and deployed on Vercel.

## Local setup

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and add development credentials as needed.
4. Run `npm run dev`.

Use `npm test` for the foundation checks and `npm run build` for a production build.

## Editing the site (Kim and Cortney)

1. Ask the site administrator to add your GitHub account to the GCC website repository.
2. Visit `https://grandmascatcoalition.org/admin/` and choose **Login with GitHub**.
3. Choose the section you want to edit, make the change, and save it.
4. Choose **Set status → Ready** when the change is ready for review. The editor creates a reviewable change before it goes live.

Do not paste private animal, adopter, donor, or payment information into the website editor.
