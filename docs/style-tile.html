Rules for Codex
1. Put every value above in src/tokens.css as the :root variables shown in this file's source — use variables, never raw hex in components.
2. Photos over illustrations. Real cats, real people, warm light. No clip-art paws/whiskers.
3. Rounded corners (16px cards, pill buttons), soft shadows, generous whitespace. Max content width 1120px.
4. Gold appears only on Donate. Purple 900 only for hero/footer backgrounds and headings. Sage for tints, tags, secondary buttons, eyebrows.
5. Emoji in this tile are placeholders — never ship them.
