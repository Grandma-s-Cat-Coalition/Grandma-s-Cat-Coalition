Rules for Codex

  1. Copy the :root block from this file into src/tokens.css. Components use variables only — never raw hex.
  2. Wordmark = Grandma's (Kaushan, Plum 700) + CAT COALITION (Fraunces 700, tracked; Sage 900 on light, white on dark). Kim's square logo → public/images/brand/logo.png; banner → public/images/brand/banner.jpg (OG image, FB header). Cortney will drop both files in.
  3. Script is an accent only: max one script phrase per heading; never below 28px; never in buttons, nav, forms, or body.
  4. Motifs from her designs, used sparingly: small paw/heart icons (Plum 700 or Sage 500), soft sage watercolor washes in section corners, a sage cat-silhouette band above the footer. Real cat photos do the heavy lifting.
  5. Backgrounds alternate Cream → Sage 100 → white cards. Plum 900 only for hero and footer.
  6. Gold appears only on Donate; one per screen.
  7. No hollow outline buttons. Pill shape, Lato 900. Soft buttons carry a 2px Plum 200 edge.
